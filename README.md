# ASKAIA Piano

Privates, natives Android-**Kompositions-Skizzenbuch** für das Digitalpiano.
Aufnehmen, ansehen, langsam nachüben — ohne Konto, ohne Tracking, ohne Werbung.

---

## 📥 Download & Installation

**Immer die neueste Version (ein Link für immer):**

👉 **https://github.com/Askaian/ASKAIA-Piano/releases/latest/download/ASKAIA_Piano.apk**

### So installierst du
1. Den Link oben auf dem Android-Handy antippen und die Datei **`ASKAIA_Piano.apk`** herunterladen.
2. Beim Öffnen fragt Android einmalig, ob Apps aus dieser Quelle (z. B. deinem Browser) installiert werden dürfen → **erlauben**.
3. Auf **Installieren** tippen — fertig.

> Die App ist bewusst nicht im Play Store. Die Installation aus einer APK ist normal, solange die Datei aus diesem Repo stammt.

## 🔁 Updates
Die App **sucht beim Start selbst nach neuen Versionen** und meldet sich, wenn eine bereitsteht.
Du kannst auch jederzeit unter **Einstellungen → Nach Updates suchen** nachsehen.
Neue Versionen lassen sich direkt **über die bestehende App** installieren — deine Aufnahmen bleiben erhalten (gleiche Signatur).

## 🎹 Was die App kann
- **Jam** — Verbindung zum Roland FP-90 über Bluetooth-MIDI, gespielte Tasten leuchten live auf
- **Aufnehmen** — Spiel mit exaktem Timing, Anschlagstärke und Sustain-Pedal festhalten
- **Piano-Roll** — fallende Balken im Synthesia-Stil, Tempo stufenlos regelbar zum Nachüben, Abschnitts-Loop
- **Klang** — über das FP-90 oder über den eingebauten Klavierklang, auch ohne angeschlossenes Piano
- **Songs** — Audiodateien auswerten: **Akkorde, Tonart und passende Tasten**, oder jede einzelne Note als Piano-Roll
- **Einsingen** — eine Melodie summen oder singen und als Skizze festhalten (in Entwicklung)
- **MIDI-Import**, Papierkorb, Sicherung als ZIP

## 🔒 Datenschutz & Sicherheit
- Läuft vollständig offline. Der **einzige** Netzzugriff ist die Update-Suche auf GitHub — kein Konto, kein Tracking.
- **Bluetooth** wird ausschließlich für die MIDI-Verbindung zum Piano genutzt (kein Standortzugriff).
- **Mikrofon** wird ausschließlich für die Funktion „Einsingen" genutzt.
- Hier werden **ausschließlich die fertigen App-Dateien (APK)** bereitgestellt — der Quellcode ist nicht öffentlich.
